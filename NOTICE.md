# Notices and attribution

## ProsperoTV

Prosper LG TV is an adaptation, for LG webOS TVs, of **ProsperoTV**:

- Project: https://github.com/blackbearreloaded/ProsperoTV
- Author: blackbearreloaded and ProsperoTV contributors
- Licence: GNU General Public License v3.0 or later

Prosper LG TV's code is a new JavaScript implementation for the webOS web runtime. It does not contain ProsperoTV's C/C++ sources, its PS5 runtime, its interface artwork, fonts or icons. It does follow ProsperoTV's product design and behaviour, documented in ProsperoTV's README and sources (notably `src/iptv_catalog.cpp`, `src/iptv_app.cpp` and `src/iptv_player.cpp`):

- the offline-first, last-good catalog of M3U playlists;
- the extended-M3U attributes it honours (`tvg-*`, `group-title`, `#EXTVLCOPT` user agent and referrer);
- search, and the country, language, category and quality filters (SD / HD 720p / Full HD 1080p / 4K);
- favourites, recent channels, and returning to the channel last watched;
- merged alternate streams with automatic fallback, recovery from stalled live streams, and specific failure reasons;
- the playback statistics overlay;
- the decision not to support DRM.

Because Prosper LG TV is based on ProsperoTV's design, it uses the same licence, GPL-3.0-or-later (the `LICENSE` file is identical to ProsperoTV's), so it can be treated as a derivative work. Prosper LG TV is not affiliated with or endorsed by ProsperoTV's authors. Problems with Prosper LG TV should be reported to Prosper LG TV (https://github.com/pustal/ProsperLGTV), not to ProsperoTV.
